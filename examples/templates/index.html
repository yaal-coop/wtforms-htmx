wtforms-htmx

A small gallery demonstrating the pieces of the library.

Attendance grid

Doodle-style 2D availability grid: rows (users) and columns (dates) can be added or removed at runtime, each cell cycles through (present → unknown → absent) on click. Six custom mutations on a flat FieldList; the form is never validated or saved. Every click is a pure state transition.

Auto-save

The save button listens to every field with .triggered_by("*", on="input delay:800ms") and commits the form on every typing pause. The whole form must validate; otherwise a status pill reports the error count and the underlying state stays untouched. Manual submit button kept for the no-JS fallback.

Combobox

Single-text-entry picker backed by a server-filtered popup listbox. The query input refreshes the suggestions as the user types; clicking a suggestion fires value_add through .triggers(), the chip's × runs value_remove.

Currency converter

EUR ⇆ JPY bidirectional converter. Typing in either field updates the other without moving the caret. Companion → JPY / ← EUR buttons run the same mutations on click, with or without JavaScript.

Cycle button

One button that rotates a hidden value through a fixed list on every click, with the built-in cycle_through(values) mutation on a HiddenField. Same recipe as the cells in the attendance grid, distilled to a single value.

Datalist autocomplete

A single StringField with a callable DataList filtered server-side. Typing refreshes the <datalist> options, with no custom JavaScript and a browser-native suggestion popup.

Dual listbox

Two-column shuttle on a SelectMultipleField: Available ↔ Selected. Layers live per-column search (via StringField.triggers), header counters, Add all / Clear all bulk moves that honor the active filter, avatars on each row, and an aria-live region, all on top of the same value_add / value_remove wiring as the tag picker. References: Ant Transfer, SLDS Dueling Picklist, Bootstrap Italia Transfer.

Dynamic address form

Delivery + billing blocks with an opt-in copy. Country drives a server-side postal code → city + region lookup; the billing block is conditionally revealed and pre-filled. Combines FormField nesting, datalists, and cross-field triggers.

Faceted search

Catalog-of-books search with chips for active filters, an inline panel for the five facets, and a result list that updates on every change. The Author autocomplete reads the values of its sibling facets (genre, language, year range) and tightens its suggestions accordingly, the cascade that defines faceted search.

Inline edit

A read-only label paired with an edit button. Click ✏ Edit to flip into edit mode (input editable, button becomes ✓ Save); click ✓ Save to commit and revert to read-only. Same cycle_through recipe as the cycle button, on two values driving the wrapper's rendered UI.

Inline validation

A settings-like form revalidated on blur. Showcases WTForms' native Email, URL, NumberRange and Length validators.

Invoice totals

Per-row VAT-aware totals declared inside a nested FormField. Add / remove lines, live row total, invoice-level subtotal / VAT / grand total recomputed as the user types, via out-of-band swaps.

Markdown preview

A textarea drives a server-rendered markdown preview into a <div> that is not a form field. Uses the htmx selector syntax in .triggers("#preview", …); mistune renders the markdown on each typing pause.

Pagination

Page-by-page navigation built from a single SelectField: each numbered page and the ← / → arrows are options rendered as buttons via option_widget=Button(). Clicking any of them binds the new page naturally. Prev/Next need no custom mutation, their target page is computed at render time.

Password strength indicator

Live-scored password meter plus a confirmation field. Typing recomputes the strength via a custom mutation; the EqualTo validator gates the matching status next to the confirm input.

Tag picker

Chip picker on a SelectMultipleField: selected values appear as chips, the unselected ones as a catalog strip of buttons. value_add and value_remove wire the add / remove buttons without a custom mutation.

Task list

A draggable TODO list: append, remove, move up or down, and drag-to-reorder on a FieldList(FormField). Combines list_add, list_remove, list_move and list_reorder; per-row validation and form-level save in the same submit cycle.

Title slug

A title input derives a slug field. Typing normalizes the title to ASCII / kebab-case on the fly, until the user edits the slug by hand.
